# Work unit

- Store records at `~/Projects/<project>/.agents/work-units/<id>.json`.
- Before starting/resuming work or selecting/removing linked resources, [recover context](references/read.md).
- On creation or scope, participant, or link changes, [save the unit](references/save.md).
- Use workspace configuration with `asana-cli`, `glab`, and `wt`.
- Skip unrelated CLI questions.
