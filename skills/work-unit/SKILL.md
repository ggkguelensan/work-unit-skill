# Work unit

- Store units in their project root: `~/Projects/<project>/.agents/work-units/<id>.json` (for example, `~/Projects/ticketon/.agents/work-units/`).
- Before starting/resuming work or selecting/removing linked resources, [recover its context](references/read.md).
- On creation or changes to scope, participants, or links, [save the unit](references/save.md).
- Follow workspace configuration; use `asana-cli`, `glab`, and `wt` for their objects.
- Skip unrelated CLI questions.
